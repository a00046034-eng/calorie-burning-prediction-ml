
# Calorie Burning Prediction Using Machine Learning

## Project Overview
This project explores the use of machine learning to predict calories burned during physical activity.

The aim was to compare different machine learning algorithms, evaluate their accuracy and understand how data can be used to make predictions.

## Technologies Used
- Python
- Scikit-learn
- NumPy
- Matplotlib
- Jupyter Notebook

## Machine Learning Models
Four regression models were explored:

1. Linear Regression
2. K-Nearest Neighbours
3. Random Forest
4. Gradient Boosting

## Project Implementation
The project involved:

- Data preprocessing and preparation
- Splitting data into training, validation and testing sets
- Training machine learning models
- Evaluating predictions using R² and Mean Absolute Error (MAE)
- Visualising results using Python
- Comparing model performance

## Skills Demonstrated
- Python programming
- Machine learning fundamentals
- Data analysis
- Predictive modelling
- Model evaluation
- Data visualisation

## Dataset
The notebook uses a calorie-burning dataset and expects a file named `calories.csv`.

The dataset is not currently included in this repository.
